## 各阶段详细内容

### 第 0 阶段：环境搭建与前置知识
**目标**：能编译、运行第一个 CUDA 程序，并能查询设备信息。

- 硬件与驱动检查（`nvidia-smi`、计算能力概念）
- CUDA Toolkit 安装（Windows / Linux，含 apt 与 runfile 两种方式）
- 前置知识补齐（体系结构、并行概念、内存层次直觉）
- 第一个程序 `hello.cu`：理解 `<<<1,1>>>` 与主机/设备代码分离
- **验收**：能独立用 `nvcc` 与 CMake 各编译并运行一个 CUDA 程序
- 📄 详细内容：[第 0 章 环境搭建与第一个程序](ch00_环境搭建与第一个程序.md)

### 第 1 阶段：CUDA 编程模型入门
**目标**：彻底理解 grid / block / thread 与 SIMT 执行模型。

- 异构计算模型、`__global__` / `__device__` / `__host__`
- 四个内建变量：`threadIdx`、`blockIdx`、`blockDim`、`gridDim`
- 一维 / 二维 / 三维索引公式推导
- Grid-Stride Loop：处理任意规模数据的标准写法
- SIMT 与 warp（32 线程）、分支发散
- **验收**：能解释"一个 kernel 启动了多少线程、它们如何映射到数据下标"
- 📄 详细内容：[第 1 章 编程模型与线程索引](ch01_编程模型与线程索引.md)

### 第 2 阶段：线程组织与内存层次 ★ 第一个分水岭
**目标**：理解 GPU 内存金字塔，会用 shared memory 做优化。

- 内存类型全表（寄存器 / 共享 / 全局 / 常量 / 纹理 / 本地）
- 合并访存（Coalesced Access）原理与反例
- 共享内存、`__syncthreads()`、Bank Conflict 与 padding 消除法
- 分块（Tiling）矩阵乘法、双缓冲
- 常量内存、`__ldg`、寄存器压力与占用率
- **验收**：能说明每个优化点的理论收益，并用实测数据验证
- 📄 详细内容：[第 2 章 内存层次与访存优化](ch02_内存层次与访存优化.md)

### 第 3 阶段：同步、通信与原子操作
**目标**：掌握块内与块间协作手段。

- `__syncthreads()` 语义与死锁陷阱、`__syncwarp()`、`__threadfence()`
- Warp Shuffle 四个函数、投票函数
- 原子操作全家桶、争用问题、自旋锁
- Cooperative Groups 与网格级同步
- 流（Stream）、异步拷贝、页锁定内存、CUDA Graphs
- **验收**：能写出无死锁、无数据竞争的协作型 kernel
- 📄 详细内容：[第 3 章 同步通信与原子操作](ch03_同步通信与原子操作.md)

### 第 4 阶段：性能分析与优化方法论
**目标**：从"猜"变成"测"，形成可复现的优化闭环。

- 优化思维五步框架
- 带宽 / GFLOPS / 算术强度 / Roofline 模型
- Nsight Compute（ncu）与 Nsight Systems（nsys）实操
- 编译选项详解、PTX/SASS 查看
- compute-sanitizer 排查内存错误
- **验收**：能对任意 kernel 写出瓶颈判断报告并验证优化效果
- 📄 详细内容：[第 4 章 性能分析与优化方法论](ch04_性能分析与优化方法论.md)

### 第 5 阶段：核心算法模式实战
**目标**：掌握 GPU 通用并行模式，能迁移到新问题。

- Reduce（四步演进）、Scan（Kogge-Stone / Blelloch）
- Stencil（共享内存 tiling + halo）
- Sort（双调排序、基数排序）、SpMV（CSR / ELL）
- 图算法（BFS）、数值精度（Kahan、分块求和）
- **验收**：能独立把新算法拆解成已知的并行模式
- 📄 详细内容：[第 5 章 核心算法模式实战](ch05_核心算法模式实战.md)

### 第 6 阶段：CUDA 高级特性
**目标**：掌握现代 GPU 架构相关的高级能力。

- 动态并行（CC ≥ 3.5，需 `-rdc=true`）
- Tensor Core / WMMA（CC ≥ 7.0）
- 异步拷贝 `cp.async`（CC ≥ 8.0）
- 线程块集群与分布式共享内存（CC ≥ 9.0）
- 统一内存进阶、VMM、多 GPU P2P
- **验收**：能判断某个特性是否适用于自己的硬件与问题
- 📄 详细内容：[第 6 章 CUDA 高级特性](ch06_CUDA高级特性.md)

### 第 7 阶段：生态、库与工程化
**目标**：不重复造轮子，能把 CUDA 融入真实工程。

- cuBLAS / cuFFT / cuRAND / cuSPARSE / cuDNN / Thrust / CUB
- Python 衔接：CuPy、Numba、PyTorch 扩展、Triton
- CMake 工程化、CPU 回退、单元测试
- 跨平台视野（HIP / SYCL / OpenCL）
- **验收**：能判断该用库还是自己写，并搭出可交付的工程
- 📄 详细内容：[第 7 章 生态库与工程化](ch07_生态库与工程化.md)

### 第 8 阶段：综合项目与结业
**目标**：完成一个可展示的完整项目。

- 主推：高性能 SGEMM，从朴素优化到接近 cuBLAS（7 个渐进版本）
- 备选：光线追踪器、N 体模拟、CNN 推理核、SpMV/CG 求解器
- 性能报告撰写、profile 数据整理
- **验收**：带 README 的仓库 + 性能报告 + 正确性验证脚本
- 📄 详细内容：[第 8 章 综合项目实战](ch08_综合项目实战.md)

## 结业能力自检

完成全部阶段后，你应当能做到：

- [ ] 独立设计 kernel 的线程映射与内存布局
- [ ] 用 ncu / nsys 定位瓶颈并说出理由
- [ ] 熟练应用合并访存、shared memory tiling、warp shuffle、异步拷贝
- [ ] 判断一个问题该自己写 kernel 还是用 cuBLAS / Thrust / CUB
- [ ] 搭建 CMake 工程并保证 CPU / GPU 双路径可编译
- [ ] 有至少一个可展示的完整项目

---

## 一句话建议

> CUDA 的难点不在语法，而在"数据怎么摆放、线程怎么映射、瓶颈在哪里"。
> 每写一行优化代码，都要能说出它改善了什么、为什么有效。
